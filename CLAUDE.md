# Project: AliExpress Toolkit

## Goal
A javascript for enhancing the AliExpress shopping experience.

## Background / context
- Who it's for: Me

## Requirements
### Must have
- Automatically redirects bundle deal pages to the single product page
-  Remove unnecessary parameters from Aliexpress URLs 
- Removes Max Combo, bundle and SuperDeals cards that aren't real products, sorts search results by sold count, optional off-topic filter. Never reloads the page. 
- Hide help button
- Allows you to open the reviews page in a separate tab/window with infinite scrolling and expand all images.
- Display correct initial picture and not the thumbnail, so that the price is correct.
- Prefer text on product description, push images below.
- Product description and reviews splitscreen.
- Proper Github README for the script
### Nice to have
- Fixes AliExpress CSS to show full product names 
-  Toggle filter with 4 states: All products, Hide bundles, Show only bundles, Hide choice 
-  Prevent unwanted redirects on AliExpress 
-  Removes zoom functionality on product images allowing copy and save image 
-  When viewing past Aliexpress orders, auto-click the "View orders" button when it comes into view. 
- Resize unimportant things to become smaller.
